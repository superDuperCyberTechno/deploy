This project contains a bash deployment script for websites, designed to be source-agnostic. Uses boilerplate config files for different templates, downloaded from the public GitHub repository. Uses rsync to synchronize files and SSH to manage permissions and execute external commands with deployment server.

When working on this project, follow these rules...
- Maintain concise and easy to read comments, across the source code
- Automatically maintain the semantic versioning and notify the user when doing so
